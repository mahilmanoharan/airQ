## Architecture by area
- **Schema/store** (`RespiratoryKit/Schema/`): V1 frozen legacy `DetectionEvent`; V2 and V3 **frozen** (V3 only adds `DailyCheckIn.controllerAdherence`; any model change = SchemaV4 + a migration stage). One container shared by `DetectionStore`, `RecordStore`, `RecordExporter`, in the App Group (`Shared/AppGroup/<uuid>/Library/Application Support/default.store`). Governing rule: store raw observations, derive at read time; annotations/check-ins/context events are append-only (latest row wins). Blobs carry a SwiftData marker byte: never read the SQLite raw; export reads through SwiftData.
- **Providers** (`AirQualityKit`): every WAQI / Pollen / Google-AQ request yields a full `ProviderAttempt` (raw body, HTTP status, rounded coordinate, provider message) reported via `onProviderAttempt` (incl. `locationUnavailable`, `skippedBudget`, `notSent`). `RollingRequestBudget` counts persisted attempts. Coordinates are rounded to 2 decimals. Pollen: `days=5` (billed per successful request, ≤ 1/day; day 1 parsed, outlook + plants on the reading; Google's forecast dates are **UTC-based**, keyed with `DayKey`); 2xx and non-408/429 4xx settle the day, 408/429/5xx retry. Google history must use `hours` (1–720); its entries carry indexes only (`uaqi`, `usa_epa`), no concentrations. WAQI `iaqi` are sub-indices, not concentrations. `pollenIndex == nil` = unavailable, never 0.
- **Dashboard loading** (`DashboardViewModel`): loads coalesce; cache reused when fresh (< 1 h) and within 1 km; an explicit refresh reuses a reading < 60 s old unless the previous load failed; `LoadGate` (shared by the foreground and background models) makes two models sharing a cache fetch once; on a location failure the last cached reading is shown under a banner.
- **Background refresh + alerts** (`airQ/BackgroundRefresh.swift`, `AppServices.swift`, `AirQualityAlerts.swift`): a BGAppRefresh run ≥ `freshFor + 5 min` out refreshes the **cached place** (`CachedPlaceLocation`: no CoreLocation, no geocoding), records attempts through `OrderedTaskQueue` (flushed before the run returns), never marks a record day, and posts opt-in local alerts (`AirQualityAlertPolicy`: air AQI 51/101/151, pollen index 2/3/4; fresh reading / today's forecast; each kind ≤ 1 per local day, day saved right after the post; **quiet hours 22:00–07:00 local**: nothing is sent, nothing recorded, so the first run from 07:00 sends a still-current alert). If the app was never located, a run does nothing. A user who moves keeps the old place on widgets until the app is opened. `AppServices.shared.prepare()` opens the container once for the UI and the background path.
- **Capture** (semantics 2): every 3 s window stored with allowlist + confounder scores, top-3, rms/peak, inside a `ListeningSession` with an end reason; store-owned ingest task; `wheeze` / `throat_clearing` do not exist as labels on `SNClassifierIdentifier.version1`.
- **Records / Trends / Export**: Records diagnostics; check-in question set 2 (yes/partly/no/notPrescribed medication answer); Trends read-time series incl. a context lane, **by hour of day** (events + listening minutes per local hour) and no composite scores; the dashboard's **Past 30 days** card (each local day in the category of its highest Google hourly value; days with < 18 stored hours are left out and counted). Export: 10 CSV tables + `data_dictionary.csv` + `manifest.json` (SHA-256) + README + `raw/`, complete-or-fails row-count checks, optional **period** (`ExportPeriod`: rows included by when recorded; stated in manifest/README/notes; not a backup). Export text cells are verbatim (a spreadsheet may evaluate a leading `= + - @`; noted in the export).
- **Request ledger** (`RequestLedger`, UserDefaults): provider name + request time only, for the trailing 32 days, written by `eraseAll` from the attempts it deletes; `RecordStore.providerRequestCount`/`latestRequestAt` add it, so erasing can't reset the free-tier count.
- **Erase all data** (user-confirmed, the only deletion; `EraseDataView` / `DataEraser` / `RespiratoryStore.eraseAll`): batch-deletes every model, clears the shared snapshot/place, tuning, mic consent, last-export time and `tmp/Exports`, keeps alert/export preferences; sets `airQErasePending`, and the next `openContainer()` removes the store files **only if no user-authored rows exist** (provider rows don't count). Verified end to end on a scratch simulator.
- **Widgets**: four kinds (AQI, Pollen, Combined, Outlook) + Lock Screen accessories; staleness ≥ 3 h shown; timelines precomputed for the stale moment and local midnight; they only read the cache.
- **Navigation**: a `TabView` of `AppTab` (Today, History, Report, More), each with its own NavigationStack; check-in opens in Today, listening in More, raw export in Report; `menuSections` covers the optional More routes. Every link (`airq://<route>`, Siri's `OpenScreenIntent`, the controls' `OpenScreenControlIntent`, alert taps) goes through `NavigationRouter.pendingPath` → `TabDestination`. Siri's `AirQScreen` must stay exhaustive over `AppRoute`; `ControlScreen` raw values must match it (DEBUG assert in `airQApp.init`). Siri: current-air-quality and guidance shortcuts speak the cached reading (guidance = the EPA text for the category), never fetching.

## Gotchas
- SwiftData caches one class per entity name per process: inserting `SchemaV2.DailyCheckIn` while V3 objects exist crashes (`controllerAdherence` key) — the V2→V3 test migrates the committed fixture `RespiratoryKitTests/Fixtures/SchemaV2Store` (regenerate alone: `WRITE_V2_FIXTURE=<dir> swift test --filter writeV2Fixture`). A `ModelContext` doesn't retain its container.
- A `.task` on a `Group` whose only child is a false `if` never runs; always render a container (`RecentAirQualityCard`, `MonthAirQualityCard`).
- `@AppStorage`/UserDefaults persist on the simulator across UI-test runs: a test that changes one must set its own start state and restore it.
- iOS 26 `confirmationDialog` has no findable "Cancel" button in XCUITest (tap outside). `xcrun simctl openurl` raises an "Open in airQ?" alert that can't be dismissed without taps (reboot the sim); `XCUIApplication.open(url)` doesn't prompt. Editing the App Group plist directly is overwritten by cfprefsd; use `simctl spawn <udid> defaults write <plist path without .plist> … -data <hex>`.
- A fresh sim needs `simctl privacy <udid> grant location mahilmanoharan.airQ` after install; revoke/re-grant to test denial. The simulator clock/timezone may be US Eastern while its location is San Francisco.
- `INFOPLIST_KEY_*` synthesis only works for Apple-recognized keys; custom keys go through `InfoPlistAdditions.plist` (which also holds `CFBundleURLTypes`, `BGTaskSchedulerPermittedIdentifiers`, `UIBackgroundModes`). `AQService.swift` and `Secrets.xcconfig` are git-ignored; never print their values.
- The UI-test target is hand-edited in the pbxproj (IDs `A4F1…A1–AB`, synchronized folder `airQUITests/`); there is no shared scheme (Xcode's autogenerated `airQUITests` scheme works from the CLI).
